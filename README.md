An intelligent Artificial Intelligence & Machine Learning service powering **Code4Welfare**, designed to automate eligibility assessment, optimize social welfare scheme recommendations, detect anomalies, and streamline public aid delivery.

---

## 🌟 Features

- 🎯 **Eligibility Prediction & Matching**: Machine learning models evaluating user profiles against welfare scheme criteria.
- 💡 **Smart Recommendation Engine**: Personalized scheme suggestions based on socio-economic indicators and demographic data.
- 📊 **Resource & Aid Allocation**: Predictive analytics to guide public resource distribution efficiently.
- 🔍 **Anomaly & Fraud Detection**: Flagging suspicious or duplicate benefit requests to ensure equitable aid.
- 💬 **Intelligent Assistant API**: NLP pipeline for conversational querying of welfare policies and support.

## 🚀 Getting Started

### Prerequisites

- Python 3.9+
- Git

### Installation

1. **Clone the repository:**
   ```bash
   git clone -b AI_Engine https://github.com/SaiGokul654/Code4Welfare.git
   cd Code4Welfare
   ```

2. **Set up a Virtual Environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
